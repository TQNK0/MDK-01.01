# Введение в C++

## Язык программирования C++
**C++** — это высокоуровневый компилируемый язык программирования общего назначения со статической типизацией.

---

### История создания

* **Корни языка**  
  Язык C++ неразрывно связан с языком **C**, который разработал программист **Деннис Ритчи** в **1969–1973 годах** в лаборатории **Bell Labs**.

* **Появление C++**  
  В начале 1980-х годов датский программист **Бьёрн Страуструп** (также сотрудник Bell Labs) создал C++ как расширение к языку C.

* **Первое название**  
  Изначально проект назывался **«C с классами»**, так как его главной целью было добавление в язык C возможностей объектно-ориентированного программирования (ООП).

---

### Особенность компиляции

C++ является **компилируемым языком**. Это означает, что специальная программа — **компилятор** — транслирует исходный текстовый код в готовый исполняемый файл, который содержит набор прямых машинных инструкций для процессора.

---

### Основные компиляторы

1. G++  
2. Clang  
3. MSVC (Microsoft Visual C++)

---

### Состав компилятора g++

1. `cpp` — препроцессор  
2. `as` — ассемблер  
3. `g++` — непосредственно компилятор  
4. `ld` — линкер (редактор связей)

---

### Зачем нужно компилировать исходный C++ файл

Исходный файл C++ — это всего лишь код, но его невозможно запустить как программу или использовать как библиотеку. Поэтому каждый исходный файл требуется скомпилировать в исполняемый файл.

---

### Этапы компиляции

1. **Препроцессинг** — препроцессор преобразовывает программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными директивами (например, `#include`, `#define`, условная компиляция и т.д.).

2. **Компиляция** — на этом этапе препроцессированный код переводится в ассемблерный код для конкретной архитектуры процессора.

3. **Ассемблирование** — ассемблер превращает ассемблерный код в объектный код (машинные инструкции) в виде объектного файла (`.o` или `.obj`). 

4. **Компановщик(Линкер)** — линкер объединяет все объектные файлы и библиотеки в один исполняемый файл, разрешая внешние ссылки между ними.
